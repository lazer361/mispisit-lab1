# Shortener

Сервис для тех, кому нужно сократить длинную ссылку и поделиться ею.

## Запуск

```text
Репозиторий: https://github.com/lazer361/mispisit-lab1
Pull Request: https://github.com/lazer361/mispisit-lab1/pull/1
Образ: https://hub.docker.com/r/lazer361/mispisit-lab1

docker pull lazer361/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 lazer361/mispisit-lab1:0.0.1
```

Страница открывается по адресу http://localhost:8080.
