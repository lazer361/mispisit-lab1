# Shortener

Сервис для тех, кому нужно сократить длинную ссылку и поделиться ею.
На странице «Состояние» видно, доступна ли база и какая короткая ссылка создана последней.

## Функции

- Создание короткой ссылки по исходному URL.
- Просмотр списка с названием, категорией, исходным и коротким адресами.
- Переход на исходный сайт по короткому адресу. Для неизвестного кода открывается страница ошибки.
- Просмотр состояния базы и последнего создания ссылки с её названием, кодом и временем.

## Правила

- Исходный URL обязателен и должен начинаться с `http://` или `https://`.
- Название необязательно, до 255 символов. Если его оставить пустым, используется имя сайта.
- Категория необязательна, до 60 символов. Для старых ссылок и при пустом поле используется «Без категории».
- Шестизначный код создаётся автоматически и уникален. Событие записывается только при успешном создании ссылки.

## Запуск

```text
Репозиторий: https://github.com/lazer361/mispisit-lab1
Ветка: lab6
Pull Request: https://github.com/lazer361/mispisit-lab1/pull/6
Образ: lazer361/mispisit-lab1:0.0.6

git clone -b lab5 https://github.com/lazer361/mispisit-lab1
cd mispisit-lab1
docker compose up -d

git checkout lab6
docker compose stop app
docker compose run --rm -v ./backup/pre-release:/backup backup
docker compose up -d

docker compose run --rm backup
docker compose down -v
docker compose up -d db
docker compose run --rm restore
docker compose up -d
```

После первого `docker compose up -d` откройте http://localhost:8080 и создайте ссылку. В версии 0.0.5 до создания первой ссылки событий нет. После создания на странице «Состояние» появятся название ссылки, короткий код и время создания.

После запуска 0.0.6 проверьте эту ссылку в списке. У неё должна появиться категория «Без категории». Последний блок команд удаляет том тестовой базы и восстанавливает его содержимое из копии. После запуска снова откройте список ссылок.

## Резервная копия

Команда `docker compose run --rm backup` сохраняет копию в `backup/app.sql`. Копия до обновления остаётся отдельно в `backup/pre-release/app.sql`.

На время восстановления приложение должно быть остановлено. Команда `docker compose run --rm restore` восстанавливает `backup/app.sql` после готовности базы. Для отката восстановите предыдущую копию в пустую базу командой `docker compose run --rm -v ./backup/pre-release:/backup:ro restore`, затем переключитесь на `lab5` и запустите приложение.
