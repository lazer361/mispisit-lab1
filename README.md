# Shortener

Сервис для тех, кому нужно сократить длинную ссылку и поделиться ею.
Страницы оформлены на Bootstrap 5.3.8. Файл CSS включён в образ.

## Запуск

```text
Репозиторий: https://github.com/lazer361/mispisit-lab1
Ветка: lab4
Pull Request: https://github.com/lazer361/mispisit-lab1/pull/4
Образ: lazer361/mispisit-lab1:0.0.4

git clone -b lab4 https://github.com/lazer361/mispisit-lab1
cd mispisit-lab1
docker compose up -d
```

Откройте http://localhost:8080. Через меню можно создать ссылку, открыть список или проверить отказ для неизвестного короткого адреса.
